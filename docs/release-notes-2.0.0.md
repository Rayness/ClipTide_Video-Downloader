# ClipTide 2.0.0

- Приложение стало **одним файлом**: `ClipTide.exe` вместо папки с `_internal`. Архив 101 МБ вместо 181 МБ.
- **Обновляется само**: «Настройки» → «Сеть и обновления» → «Обновить». Отдельный `update.exe` удалён.
- Интерфейс **переведён на девять языков**.
- **Починено скачивание с YouTube** — раньше любая загрузка падала с `Requested format is not available`.
- Интерфейс на Qt: Edge WebView2 Runtime больше не нужен.

**Обновление с 1.7.x:** скачайте `ClipTide.exe` вручную — старые версии перейти на 2.0 сами не могут.
Остатки прошлой установки удалятся при первом запуске. Дальше — обновление внутри программы.

---

## English

- Ships as a **single `ClipTide.exe`** instead of a folder; 101 MB archive, down from 181 MB.
- **Updates itself** — the separate updater is gone.
- Interface **translated into 9 languages**.
- **Fixed YouTube downloads** that failed with `Requested format is not available`.
- Qt interface: Edge WebView2 Runtime is no longer required.

**From 1.7.x:** download `ClipTide.exe` manually — older builds cannot update themselves to 2.0.
