# ClipTide 2.0.0

Крупное обновление: приложение стало **одним файлом**, научилось **обновляться само**
и полностью переведено на **девять языков**. Предыдущий стабильный выпуск — 1.7.3f.

---

## Как обновиться

**Если у вас 1.7.x** — скачайте `ClipTide.exe` из этого релиза и запустите.
Старые версии перейти на 2.0 сами не могут: там программа лежала папкой с
`_internal`, и подменить сотни занятых файлов на ходу нельзя. При первом запуске
2.0 сама удалит остатки прошлой установки — папку `_internal` и ненужный
`update.exe`.

**Начиная с 2.0** — обновление в «Настройки» → «Сеть и обновления» → «Обновить».
Программа скачает новую сборку, заменит себя и попросит перезапуск. Перезапуск
не автоматический: иначе обновление посреди работы оборвало бы активные загрузки.

Настройки, очередь и темы лежат отдельно от программы и обновление переживают.

## Главное

### Один файл вместо папки

Раньше поставка была папкой с `ClipTide.exe` и каталогом `_internal` на сотни
файлов. Теперь это единственный exe.

| | 1.7.0 | 2.0.0 |
|---|---|---|
| Архив | 181.3 МБ | **101.4 МБ** |
| Файлов в поставке | папка + `_internal` | **один `ClipTide.exe`** |
| Запуск до окна | — | ~2–3 с |

Portable-режим сохранён: положите рядом `portable.txt`, и данные будут храниться
в папке `userdata` возле программы.

### Самообновление без отдельного апдейтера

`update.exe` (38 МБ со своей копией Qt) удалён — вместе с ним ушёл дефект, из-за
которого апдейтер не мог обновить сам себя: он клал рядом `update.exe.new` в
расчёте, что приложение подменит файл при следующем запуске, но такого кода в
приложении не было никогда.

Теперь программа заменяет свой exe сама: Windows не даёт перезаписать запущенный
файл, но переименовать разрешает. Прежняя версия отодвигается в `.old` и
удаляется при следующем запуске. Если что-то сорвётся — старый файл возвращается
на место, и вы не остаётесь без программы.

### Девять языков

Интерфейс раньше был написан по-русски прямо в коде — словари локализации
существовали, но их никто не читал. Теперь переведено всё: загрузчик, конвертер,
редактор, уведомления и все вкладки настроек.

Русский, English, Українська, Deutsch, Français, Italiano, Polski, 日本語, 中文 —
154 строки на каждый язык.

## Загрузчик

**Исправлено скачивание с YouTube.** Загрузчик требовал у YouTube клиент `ios`.
YouTube включил SABR-only, iOS-клиент перестал отдавать прямые ссылки, и любая
загрузка падала с `Requested format is not available` — доступной оставалась
только раскадровка. Жёсткая привязка к клиенту снята, выбор оставлен yt-dlp: его
набор клиентов обновляется вместе с библиотекой.

**Заработал движок JavaScript.** QuickJS подключался ключами `ytdl_js` и
`javascript_executable`, которые нынешний yt-dlp уже не читает, — и приложение
молча работало без JS-движка, теряя часть форматов. Теперь используется
актуальный `js_runtimes`.

## Проверка обновлений

- **Больше не предлагает откатиться назад.** Версии сравнивались на «не равно»,
  поэтому сборка свежее манифеста считалась устаревшей.
- **Больше не сообщает об обновлении на ровном месте.** Версия сверялась в двух
  местах по-разному: на старте — с тегом GitHub (`v2.0.0`), в настройках — с
  манифестом (`2.0.0`). Из-за префикса `v` проверка срабатывала всегда.
- Номера с буквенным хвостом разбираются правильно: `1.7.3f` новее `1.7.3`,
  `1.10.0` новее `1.9.0`.

## Интерфейс на Qt

Интерфейс переписан с HTML/WebView на PySide6.

- **Edge WebView2 Runtime больше не нужен.** Из зависимостей ушли pywebview,
  pythonnet, clr_loader, bottle.
- **Иконки рисуются кодом** — Font Awesome с CDN не используется, иконки есть и
  без интернета.
- **Пользовательские темы продолжают работать**: палитра по-прежнему читается из
  `styles.css`, CSS-градиенты переводятся в градиенты Qt.

## Прочие исправления

- Загрузчик не освобождал семафор: после трёх скачиваний свободных слотов не
  оставалось и очередь вставала.
- Прогресс был общим на все параллельные загрузки — проценты одной задачи
  протекали в другую.
- Имя файла не экранировалось: ролик с `/` или `:` в названии создавал подпапки
  или ломал путь.
- Приложение не запускалось в оконной сборке: обработчик ошибки вывода сам
  обращался к отсутствующему потоку.
- Настройки обновлений не сохранялись из-за опечатки в имени метода.
- Отсутствие секции `Proxy` в конфиге приводило к его пересозданию с нуля —
  пользователь молча терял все настройки.
- Конвертер применял одни настройки ко всей очереди: картинка с целевым форматом
  MP4 роняла обработку.
- Падения пишутся в `Logs/crash.log` с понятным сообщением вместо безымянного
  диалога.

## English summary

**One file, self-updating, fully localized.**

- The app ships as a single `ClipTide.exe` (101.4 MB archive, down from 181.3 MB).
  The separate 38 MB updater is gone.
- It now replaces its own executable and asks you to restart. Restart is manual on
  purpose, so an update never interrupts active downloads.
- The whole interface is translated into 9 languages (previously the UI text was
  hardcoded in Russian and the translation files were unused).
- **YouTube downloads are fixed**: the app pinned the `ios` client, which stopped
  returning direct URLs after YouTube's SABR-only rollout, so every download failed
  with `Requested format is not available`.
- The bundled QuickJS engine is actually used again — it was wired through options
  that current yt-dlp no longer reads.
- Update checks no longer offer downgrades or report phantom updates.
- Qt interface: Edge WebView2 Runtime is no longer required.

**Upgrading from 1.7.x:** download `ClipTide.exe` manually — older builds cannot
update themselves to 2.0. Leftovers of the previous install are cleaned up on first
run. From 2.0 onward, use Settings → Network and updates → Update.
