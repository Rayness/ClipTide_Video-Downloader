# ClipTide 2.1.0

- **Ссылки из других программ.** `ClipTide.exe --download <ссылка>` ставит видео на загрузку и сразу начинает качать; `--format mp3 --quality 720 --minimized` — по желанию. Если ClipTide уже открыт, команду получает он — второе окно не появляется.
- **Связка с [Islet](https://github.com/Rayness/islet).** `ct <ссылка>` в островке отправляет видео в ClipTide, а прогресс загрузки виден прямо в капсуле островка.
- ClipTide запускается в **одном экземпляре**: повторный запуск выводит вперёд уже открытое окно.
- Запуск одной карточки качает **только её**, а не всю очередь.
- Исправлено: задача, добавленная в момент завершения очереди, могла остаться ждать кнопки «Начать загрузку».

**Обновление:** «Настройки» → «Сеть и обновления» → «Обновить». С 1.7.x — скачайте `ClipTide.exe` вручную.
